A pill that picks the action (preset) under the active mode: Email or Message under Reply, Like Brit. or Like Me under Write.

**The consumer provides** the preset's name, an icon (the user's own emoji, shown as typed) and an optional one-line blurb. Exactly one chip is selected; the default preset starts selected.

- Resting chips sit on `surface-sunken`; the selected chip gets a 1.5px `accent` outline, an `accent-soft` fill and an `accent-text` label.
- The blurb follows after a hairline in `ink-muted`; drop it first when space runs out, never the name.
- Chips wrap onto new lines; never scroll them sideways.
- Emoji icons come from the user, so do not use emoji elsewhere in the interface as decoration.
