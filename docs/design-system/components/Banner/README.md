A full-width notice at the top of the popup, for the shortcut-conflict warning and account problems. It uses a `warning-soft` ground with a `warning-line` outline; the lead words are `warning` and bold, the rest `ink`.

- One banner per condition, always with words. Colour alone is never the signal.
- One solid action filled with `ink` (not `accent`, so Send keeps the only accent fill) and a text Dismiss link.
- Say what is wrong and what the person can do about it, in two short sentences at most.
- Dismissing hides it for the session; it returns on the next real conflict.
