The menu bar item. On the native Mac build this is a real system menu, so draw it with `NSMenu` and the system look; this card records the content and order, not a custom style.

- Items in order: Enabled (checkbox), Show in Dock (checkbox), a separator, Settings… (⌘,), Check for Updates…, a separator, Quit Per My Last (⌘Q). There is no "Open Per My Last" item.
- Left-click opens the popup directly; the menu appears only on right-click or Control-click.
- The icon is a single-colour template image: a solid open umbrella when enabled, an outlined tilted umbrella when disabled (see the Brand assets). Swap it whenever Enabled changes.
- Show in Dock is on by default. Turning it off runs the app from the menu bar only; closing every window keeps it running.
